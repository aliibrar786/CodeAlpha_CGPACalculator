
# CodeAlpha_CGPACalculator

A simple C++ program that calculates a student's semester GPA and overall 
CGPA based on subject grades and credit hours.

## Tech Used
- C++

## How to Run
1. Compile: `g++ main.cpp -o cgpa_calculator`
2. Run: `./cgpa_calculator`
3. Enter subject grades and credit hours when prompted

## Features
- Calculates semester-wise GPA
- Calculates overall CGPA across semesters
- Simple command-line interface
